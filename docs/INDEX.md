# Document index

The managed documents, top-down. Direction lives at the top; every story's
research, spec and design are listed under it. `scripts/docs-index-check.mjs`
(CI) fails when a doc under `docs/research`, `docs/specs` or `docs/design` is
missing here, when a link here points nowhere, or when a doc breaks its shape
(see [CONSTITUTION.md](CONSTITUTION.md), C6).
